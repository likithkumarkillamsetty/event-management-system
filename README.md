# Event Management System

A full-stack web application for managing and organizing events
with secure authentication and RESTful backend services.

## 🚀 Features
- User authentication using JWT
- Event creation and management
- Search and filtering of events
- Role-based access control
- REST API architecture

## 🛠 Tech Stack
- Backend: Spring Boot
- Frontend: React
- Database: PostgreSQL
- API Testing: Postman
